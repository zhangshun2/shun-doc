🎯 动态规划核心思想

动态规划（Dynamic Programming，DP）是一种通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。

🔑 DP的三要素

  1. 最优子结构：问题的最优解包含子问题的最优解
  2. 重叠子问题：递归过程中会重复计算相同的子问题
  3. 状态转移方程：描述问题状态之间的关系

📝 DP解题步骤

  1. 定义状态：确定dp数组的含义
  2. 找状态转移方程：找到状态之间的递推关系
  3. 确定初始状态：设置边界条件
  4. 确定遍历顺序：保证计算当前状态时所需的状态已经计算过
  5. 优化空间复杂度：如果可能，降低空间复杂度

📚 总结

🎯 核心知识点

  1. 状态定义：明确dp数组每个位置的含义
  2. 状态转移：找到状态之间的递推关系
  3. 边界条件：正确设置初始状态
  4. 空间优化：利用滚动数组减少空间复杂度
  5. 完全背包问题：零钱兑换和完全平方数的本质

💡 解题模式

  • 线性DP：爬楼梯、打家劫舍等一维状态问题
  • 完全背包DP：零钱兑换、完全平方数等无限使用物品的问题
  • 数组构造DP：杨辉三角等构造类问题
  • 状态压缩：利用前几个状态计算当前状态
  • 多解法对比：DP、BFS、记忆化搜索的选择

🔄 刷题建议

  1. 掌握DP思维：从暴力递归到记忆化搜索再到动态规划
  2. 熟练状态定义：准确定义dp数组的含义
  3. 练习状态转移：找到状态之间的关系
  4. 学会空间优化：滚动数组等技巧
  5. 理解经典模型：背包问题、路径问题等
