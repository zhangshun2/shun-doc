📋 题目描述

LeetCode 64. 最小路径和 (Minimum Path Sum)

给定一个包含非负整数的 m x n 网格 grid，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

说明：每次只能向下或者向右移动一步。

约束条件：

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 200
  • 0 <= grid[i][j] <= 100

🔍 六步分析法详解

第一步：问题具体化

关键词提取：

  • “最小路径和” → 优化问题
  • “从左上角到右下角” → 起点终点确定
  • “只能向下或向右” → 移动限制
  • “路径上数字总和” → 累积计算

问题本质：
这是一个典型的路径优化问题，需要在所有可能路径中找到代价最小的那条。

第二步：递归思维分解

核心观察：
要到达位置 (i,j)，只能从两个位置来：

  • 从上方 (i-1,j) 向下移动
  • 从左方 (i,j-1) 向右移动

递归关系：

第三步：状态定义

状态选择：
dp[i][j] = 从起点 (0,0) 到位置 (i,j) 的最小路径和

状态特点：

  • 清晰性：明确表示到达某点的最优解
  • 完整性：覆盖所有可能的子问题
  • 最优性：便于状态转移和结果提取

第四步：状态转移方程

核心转移：

转移逻辑：

  • 当前位置的最小路径和 = 当前格子值 + 上方和左方的最小值
  • 体现了”最优子结构”：局部最优导致全局最优

第五步：边界条件

边界分析：

  1. 起点：dp[0][0] = grid[0][0]
  2. 第一行：只能从左边来，dp[0][j] = dp[0][j-1] + grid[0][j]
  3. 第一列：只能从上边来，dp[i][0] = dp[i-1][0] + grid[i][0]

第六步：计算顺序与结果提取

计算顺序：

  • 从左到右，从上到下
  • 保证计算 dp[i][j] 时，dp[i-1][j] 和 dp[i][j-1] 已计算

结果提取：

  • dp[m-1][n-1] 即为所求答案

🎨 空间优化详解

优化思路

关键观察：
计算 dp[i][j] 时，只需要：

  • dp[i-1][j]（上方）
  • dp[i][j-1]（左方）

优化策略：
使用一维数组 dp[j] 表示当前行的状态：

  • dp[j] 更新前：表示上一行第j列的值
  • dp[j-1]：表示当前行第j-1列的值

📊 复杂度分析

时间复杂度

  • 所有方法：O(m × n)
  • 需要遍历整个网格一次

空间复杂度

  • 标准DP：O(m × n) - 需要二维DP表
  • 空间优化：O(n) - 只需一维数组
  • 原地修改：O(1) - 直接修改输入数组

📚 总结与学习建议

🎯 核心思想

  1. 最优子结构：到达某点的最优路径包含到达前驱点的最优路径
  2. 状态转移：当前状态由有限个前驱状态决定
  3. 边界处理：第一行和第一列需要特殊初始化
  4. 空间优化：利用状态转移的局部性减少空间复杂度

🔧 解题技巧

  1. 画图分析：用网格图理解状态转移关系
  2. 边界优先：先处理边界条件，再考虑一般情况
  3. 逐步优化：先实现标准版本，再考虑空间优化
  4. 测试验证：用小规模例子验证算法正确性

📈 学习路径

  1. 掌握基础：理解二维DP的状态定义和转移
  2. 练习变体：尝试不同的路径问题
  3. 优化技巧：学习空间优化的通用方法
  4. 扩展应用：探索更复杂的路径优化问题

💡 面试要点

  1. 思路清晰：能够快速识别为路径DP问题
  2. 代码规范：正确处理边界条件
  3. 优化意识：主动提出空间优化方案
  4. 扩展思考：讨论相关变体和应用场景
