📋 题目描述

LeetCode 5. 最长回文子串 (Longest Palindromic Substring)

给你一个字符串 s，找到 s 中最长的回文子串。

回文串定义： 如果字符串正着读和倒着读都一样，那么这个字符串就是回文串。

  • s 仅由数字和英文字母组成

🔍 问题分析与解法概览

问题特点

  1. 子串问题：需要考虑所有可能的子串
  2. 回文特性：具有对称性质
  3. 最优化目标：找到最长的满足条件的子串

解法对比

方法时间复杂度空间复杂度特点
暴力枚举O(n³)O(1)简单直接，效率低
中心扩展O(n²)O(1)直观易懂，空间最优
动态规划O(n²)O(n²)区间DP经典应用
Manacher算法O(n)O(n)最优解，实现复杂

💻 方法一：动态规划（区间DP）

核心思想

区间DP的特点：

  • 状态表示一个区间的性质
  • 通过较小区间推导较大区间
  • 适合处理子串、子序列问题

六步分析法

第一步：问题具体化

关键观察：

  • 回文串的子串去掉首尾字符后仍是回文串
  • 单个字符一定是回文串
  • 两个相同字符组成的字符串是回文串

第二步：递归思维分解

递归关系：

第三步：状态定义

状态选择：
dp[i][j] = 字符串 s 从索引 i 到 j 的子串是否为回文串

状态含义：

  • dp[i][j] = true：s[i...j] 是回文串
  • dp[i][j] = false：s[i...j] 不是回文串

第四步：状态转移方程

核心转移：

第五步：边界条件

  1. 单字符：dp[i][i] = true（长度为1）
  2. 双字符：dp[i][i+1] = (s[i] == s[i+1])（长度为2）
  3. 三字符：dp[i][i+2] = (s[i] == s[i+2])（长度为3）

第六步：计算顺序与结果提取

计算顺序：

  • 按子串长度从小到大计算
  • 或者按对角线方向计算
  • 保证计算 dp[i][j] 时，dp[i+1][j-1] 已计算

结果提取：

  • 在计算过程中记录最长回文子串的起始位置和长度

🧠 区间DP的核心思想

什么是区间DP？

定义： 区间动态规划是一种特殊的动态规划方法，用于解决区间上的最优化问题。

特点：

  1. 状态表示区间：dp[i][j] 表示区间 [i,j] 的某种性质
  2. 区间合并：大区间的解由小区间的解合并得到
  3. 计算顺序：按区间长度从小到大计算

区间DP的通用模板

区间DP的经典应用

  1. 最长回文子串：判断区间是否为回文
  2. 矩阵链乘法：最优加括号方案
  3. 石子合并：最小合并代价
  4. 回文子序列：最长回文子序列长度
  5. 括号匹配：合法括号序列计数
