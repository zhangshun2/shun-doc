🏠 题目1：打家劫舍 (LeetCode 198)

题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之间能够偷窃到的最高金额。

第一步：题目具体化

  • 目标：最大金额

第二步：递归分解

考虑第i个房屋：

  • 偷第i个：不能偷第i-1个，最大金额 = dp[i-2] + nums[i]
  • 不偷第i个：可以偷第i-1个，最大金额 = dp[i-1]

🎯 总结与模式识别

常见状态定义模式

模式定义适用题目
以i结尾dp[i] = 以第i个元素结尾的最优解最大子数组和、最长递增子序列
考虑前i个dp[i] = 考虑前i个元素的最优解打家劫舍、爬楼梯
到达i位置dp[i] = 到达第i个位置的最优解解码方法、股票问题
维护多状态max[i], min[i] = 第i个位置的最大/最小值乘积最大子数组

转移方程类型

  1. 选择型：dp[i] = Math.max(选择, 不选择)
  2. 累加型：dp[i] = dp[i-1] + dp[i-2]
  3. 比较型：dp[i] = Math.max(dp[i], dp[j] + value)
  4. 更新型：dp[i] = update(dp[i-1], current)

学习建议

  1. 掌握模式：识别题目属于哪种类型
  2. 状态定义：明确dp[i]的含义
  3. 转移推导：分析所有可能的转移
  4. 边界处理：注意特殊情况
  5. 空间优化：考虑是否可以优化空间复杂度
