1️⃣ 复制带随机指针的链表 (LeetCode 138)

📝 题目描述

给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random，该指针可以指向链表中的任何节点或空节点。

构造这个链表的深拷贝。深拷贝应该正好由 n 个全新节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点。

例如，如果原链表中有 X 和 Y 两个节点，其中 X.random --> Y。那么在复制链表中对应的两个节点 x 和 y，其中 x.random --> y。

返回复制链表的头节点。

🔧 基础解法：哈希表映射

复杂度分析：

  • 时间复杂度：O(n)，其中n是链表长度，需要遍历两次
  • 空间复杂度：O(n)，哈希表存储n个节点的映射关系

🚀 进阶解法：递归 + 哈希表

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(n)，包括哈希表和递归调用栈

🚀 最优解法：原地复制（O(1)空间）

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)，不使用额外的哈希表

解题思路：

方法一：哈希表映射

  1. 第一次遍历：为每个原节点创建对应的新节点，建立映射关系
  2. 第二次遍历：根据映射关系设置新节点的next和random指针

方法二：递归

  1. 使用递归的方式深度优先遍历链表
  2. 利用哈希表避免重复创建节点
  3. 递归处理next和random指针

方法三：原地复制（最优）

  1. 在每个原节点后插入对应的复制节点
  2. 利用原节点和复制节点的相邻关系设置random指针
  3. 分离原链表和复制链表
