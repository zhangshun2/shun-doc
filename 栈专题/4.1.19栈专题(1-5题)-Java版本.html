🎯 栈的核心概念

🔑 栈的基本特性

  1. LIFO原则：后进先出（Last In First Out）
  2. 基本操作：push（入栈）、pop（出栈）、peek/top（查看栈顶）
  3. 应用场景：函数调用、表达式求值、括号匹配、回溯算法

📝 栈的高级应用

  1. 单调栈：维护栈内元素的单调性
  2. 辅助栈：使用额外栈来维护特殊信息
  3. 栈模拟递归：将递归转换为迭代
  4. 表达式处理：中缀、后缀表达式的转换和计算

2️⃣ 最小栈 (LeetCode 155)

📝 题目描述

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

  • MinStack() 初始化堆栈对象。
  • void push(int val) 将元素val推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

🔧 基础解法：辅助栈

复杂度分析：

  • 时间复杂度：所有操作都是O(1)
  • 空间复杂度：O(n)

🚀 进阶解法：单栈+差值

  • 时间复杂度：所有操作都是O(1)

📚 总结

🎯 核心知识点

  1. 栈的基本应用：括号匹配、表达式求值
  2. 辅助栈技巧：维护额外信息（如最小值）
  3. 单调栈：解决”下一个更大/更小元素”类问题
  4. 栈与递归：栈可以模拟递归过程
  5. 空间优化：使用数组模拟栈减少开销

💡 解题模式

  • 括号匹配：使用栈进行配对检查
  • 设计题：合理使用辅助数据结构
  • 字符串处理：栈处理嵌套结构
  • 单调栈应用：寻找下一个更大/更小元素
  • 面积计算：单调栈计算最大矩形面积

🔄 刷题建议
