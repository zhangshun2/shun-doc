🎯 栈的基础理论

定义与特性

栈（Stack） 是一种线性数据结构，遵循 LIFO（Last In, First Out） 原则，即后进先出。

核心特性

  1. LIFO原则：最后入栈的元素最先出栈
  2. 单端操作：只能在栈顶进行插入和删除操作
  3. 动态大小：栈的大小可以动态变化
  4. 访问限制：只能访问栈顶元素

时间复杂度

操作时间复杂度说明
push()O(1)在栈顶插入元素
pop()O(1)移除栈顶元素
peek()O(1)查看栈顶元素
isEmpty()O(1)检查是否为空
size()O(1)获取栈大小

📊 栈的子结构分类

1. 基础栈结构

特点： 标准的LIFO操作，用于简单的入栈出栈

应用场景：

  • 函数调用栈
  • 递归实现
  • 括号匹配
  • 回溯算法

核心问题：

  • LeetCode 20 - 有效的括号
  • LeetCode 155 - 最小栈
  • LeetCode 232 - 用栈实现队列

2. 单调栈结构

特点： 维护栈内元素的单调性（递增或递减）

核心思想：

  • 入栈前移除破坏单调性的元素
  • 快速找到下一个更大/更小元素
  • 解决最值问题

应用场景：

  • 下一个更大元素
  • 柱状图最大矩形
  • 每日温度问题

核心问题：

  • LeetCode 496 - 下一个更大元素 I
  • LeetCode 739 - 每日温度
  • LeetCode 84 - 柱状图中最大的矩形

3. 栈+哈希表结构

特点： 结合栈的LIFO特性和哈希表的快速查找

核心思想：

  • 栈维护元素顺序
  • 哈希表提供O(1)查找
  • 解决需要快速查找的栈问题

应用场景：

  • 快速查找对应关系
  • 优化单调栈算法
  • 处理映射问题

核心问题：

  • LeetCode 496 - 下一个更大元素 I（优化版）
  • LeetCode 1 - 两数之和（栈版本）

4. 递归栈模拟结构

特点： 用显式栈模拟递归调用栈

核心思想：

  • 避免递归栈溢出
  • 将递归转换为迭代
  • 手动管理调用状态

应用场景：

  • 深度优先搜索
  • 树的遍历
  • 图的遍历
  • 复杂递归算法

核心问题：

  • LeetCode 94 - 二叉树的中序遍历
  • LeetCode 144 - 二叉树的前序遍历
  • LeetCode 145 - 二叉树的后序遍历

5. 辅助栈结构

特点： 使用额外的栈来辅助主栈完成特定功能

核心思想：

  • 主栈存储数据
  • 辅助栈存储辅助信息
  • 协同工作解决复杂问题

应用场景：

  • 最值维护
  • 状态记录
  • 数据同步

核心问题：

  • LeetCode 155 - 最小栈
  • LeetCode 716 - 最大栈

6. 表达式栈结构

特点： 专门用于处理表达式计算和解析

核心思想：

  • 操作数栈存储数字
  • 操作符栈存储运算符
  • 处理运算符优先级

应用场景：

  • 表达式求值
  • 计算器实现
  • 编译器设计

核心问题：

  • LeetCode 150 - 逆波兰表达式求值
  • LeetCode 224 - 基本计算器

7. 状态栈结构

特点： 用栈保存和恢复状态信息

核心思想：

  • 状态压栈保存
  • 状态出栈恢复
  • 支持状态回溯

应用场景：

  • 字符串解码
  • 嵌套结构处理
  • 状态机实现

核心问题：

  • LeetCode 394 - 字符串解码
  • LeetCode 636 - 函数的独占时间

8. 栈的综合应用

特点： 结合多种栈技巧解决复杂问题

核心思想：

  • 多种技巧组合
  • 问题转化
  • 算法优化

应用场景：

  • 几何问题
  • 动态规划优化
  • 复杂数据处理

核心问题：

  • LeetCode 42 - 接雨水
  • LeetCode 85 - 最大矩形

解题思路总结

  1. 识别栈问题的关键词
    • 括号、匹配、配对 → 基础栈
    • 下一个、更大、更小 → 单调栈
    • 计算、表达式、运算符 → 表达式栈
    • 解码、嵌套、状态 → 状态栈
  2. 选择合适的栈结构
    • 简单问题 → 基础栈
    • 最值问题 → 单调栈
    • 查找优化 → 栈+哈希表
    • 递归优化 → 递归栈模拟
  3. 优化策略
    • 提前终止条件
    • 空间复杂度优化
    • 时间复杂度优化
    • 特殊情况处理

学习内容：

  2. 表达式求值算法
  3. 递归转迭代技巧

推荐题目：

  • LeetCode 496 - 下一个更大元素 I
  • LeetCode 739 - 每日温度
  • LeetCode 150 - 逆波兰表达式求值
  • LeetCode 94 - 二叉树的中序遍历

时间安排： 2-3周

高级阶段（综合应用）

目标： 能够解决复杂的栈相关问题

学习内容：

  1. 状态栈管理
  2. 栈的综合应用
  3. 性能优化技巧

推荐题目：

  • LeetCode 394 - 字符串解码
  • LeetCode 42 - 接雨水
  • LeetCode 85 - 最大矩形
  • LeetCode 224 - 基本计算器

时间安排： 3-4周

专家阶段（深度理解）

目标： 深入理解栈的原理和高级应用

学习内容：

  1. 栈的底层实现优化
  2. 实际项目中的应用
  3. 算法设计和分析

推荐项目：

  • 实现一个简单的编程语言解释器
  • 设计一个表达式计算器
  • 实现浏览器历史记录功能

时间安排： 4-6周

学习建议

  1. 循序渐进：从简单到复杂，逐步提高
