🔑 搜索算法分类

  1. 深度优先搜索(DFS)：回溯、路径搜索等
  2. 广度优先搜索(BFS)：最短路径、层次遍历等

  5. 分支限界：最优化问题的搜索

📝 搜索优化技巧

  1. 状态压缩：用位运算表示状态
  2. 记忆化搜索：避免重复计算
  3. 启发式剪枝：利用问题特性剪枝
  4. 双端队列：BFS的优化
  5. 并查集：连通性问题的优化

📝 题目描述

n 皇后问题 研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n，返回所有不同的 n 皇后问题 的解决方案。

🔧 基础解法：回溯算法

复杂度分析：

  • 时间复杂度：O(n!)，最坏情况下需要尝试所有排列
  • 空间复杂度：O(n)，递归调用栈

📝 题目描述

给你一个由 '1'（陆地）和 '0'（水）组成的的二维网格，请你计算网格中岛屿的数量。

岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。

此外，你可以假设该网格的四条边均被水包围。

示例 2：

🔧 基础解法：DFS

复杂度分析：

  • 时间复杂度：O(m * n)
  • 空间复杂度：O(m * n)，最坏情况下递归调用栈

  • 空间复杂度：O(m * n)

📚 总结

🎯 核心知识点

  1. DFS应用：单词搜索、岛屿问题等深度优先搜索
  2. BFS应用：最短路径、层次遍历等广度优先搜索
  3. 回溯优化：剪枝、预处理等优化技巧
  4. 位运算优化：N皇后等问题的状态压缩
  5. 并查集应用：连通性问题的高效解决

💡 解题模式

  • 矩阵搜索：DFS/BFS在二维数组中的应用
  • 路径问题：回溯算法寻找所有可能路径
  • 分割问题：回溯+预处理的组合优化
  • 约束满足：N皇后等约束满足问题
  • 连通性问题：DFS、BFS、并查集的选择

🔄 刷题建议

  1. 掌握基本模板：DFS、BFS、回溯的标准写法
  2. 学会优化技巧：剪枝、预处理、位运算等
  3. 理解算法选择：何时用DFS、BFS、并查集
  4. 练习复杂约束：多约束条件的处理
  5. 空间时间权衡：不同解法的复杂度分析
