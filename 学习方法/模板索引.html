模板索引

热门百题各专题的「模板题」「变形题」「综合题」对应的统一模板目录与锚点。供各文档通过标签链接跳转。

链表模板

链表加法模板

单向链表逐位相加，处理进位与尾部补节点；可扩展到多链表相加。

快慢指针模板

两个指针不同速度推进，常用于判环、找中点、删除倒数第 N 个节点。

归并链表模板

递归或迭代方式合并有序链表，稳定且便于扩展到多路归并。

快慢指针判环

Floyd 判环（龟兔赛跑），用于检测链表是否存在环。

入环位置定位

判环后通过相遇点与头指针同步移动定位入环位置。

哈希加双向链表-LRU

哈希映射 O(1) 查找 + 双向链表维护使用顺序，实现 LRU 缓存淘汰策略。

链表归并排序

快慢指针找中点 + 归并排序，对链表进行 O(n log n) 排序。

双指针相遇

两个指针从不同起点（或同起点不同速度）推进，直到相遇用于判断交点或差距。

迭代或递归反转链表

迭代三指针或递归法反转链表；递归时注意返回新头与拼接顺序。

回文链表比对

反转后半段，再用双指针从两端向中间比对节点值。

二叉树模板

二叉树遍历模板

前序/中序/后序（递归或迭代）与层序遍历（BFS）统一范式与注意事项。

DP卡特兰数

用于不同 BST 数量等计数类问题的公式与 DP 推导（Catalan）。

递归边界验证 BST

传递上下界限制，递归验证树是否满足 BST 性质。

镜像递归

判断两树是否镜像或生成镜像树的递归交换范式。

BFS层序遍历

队列分层处理，注意每层的节点数与子节点入队次序。

DFS最大深度

递归返回左右子树最大深度 + 1。

前中序还原二叉树

利用前序确定根，中序分割左右子树，递归还原树结构。

二叉树展开为链表

递归或迭代将树转为右指针单链表，注意前驱/后继拼接次序。

DFS贡献加全局最优

自底向上返回对父节点的最大贡献，同时维护全局最优路径和。

递归交换翻转树

交换左右子树指针并递归处理子树。

递归求LCA

在左右子树中查找目标，利用返回值判定最近公共祖先。

二叉树序列化与反序列化

层序或先序序列化，含空节点占位；反序列化按同序还原。

树形DP

在树结构上进行 DP 状态转移（如打家劫舍 III）。

前缀和加DFS路径计数

记录路径前缀和出现次数，配合 DFS 统计目标和路径数量。

反向中序累加（Greater Tree）

反向中序遍历，维护累加和并更新节点值。

DFS计算树径

返回节点的高度并用左右高度之和更新直径。

递归合并二叉树

递归合并同位置节点，空节点直接返回另一树。

栈与单调栈模板

栈匹配模板

括号匹配、字符串解析等栈应用，注意空栈与不匹配处理。

括号问题-栈与DP双解

最长有效括号等，可用栈或 DP 两种思路，分别给出边界与转移。

单调栈模板

维护单调递增/递减栈，解决“最近更大/更小”与面积类问题。

单调栈加DP组合

将单调栈得到的跨度/高度信息与 DP 转移结合。

栈设计最小栈

双栈或栈内存储最小值，保证 O(1) 取最小。

表达式栈解析

操作数栈 + 运算符栈，支持括号与多位数解析。

搜索与回溯模板

回溯映射模板

数字到字母映射/字典映射的回溯生成。

回溯括号模板

按剩余左右括号数进行剪枝生成合法序列。

数组重排（下一个排列）

找逆序对、交换与反转尾部实现下一个排列。

回溯组合模板

按起始索引递进，用于选数和组合问题（含剪枝）。

回溯排列模板

访问标记 + 路径构造，枚举所有排列。

回溯子集模板

每层选择/不选择，或在组合框架下不限制选择数量。

回溯剪枝与访问标记

统一剪枝准则（越界/不合法）与访问标记重置。

DFS连通块模板

网格/图的连通块计数与遍历（四方向/八方向）。

拓扑排序模板（DFS三色与 Kahn）

DFS 三色标记检测环与生成拓扑序；Kahn 入度法生成拓扑序。

BFS层级加回溯剪枝

层级最短删除、逐层扩展 + 回溯验证合法性（如删除无效括号）。

回溯或DP双路径

同一问题可用回溯或 DP，两套思路的切换与对比。

字符串模板

滑动窗口模板

左右指针扩缩窗口，维护计数或条件满足。

中心扩展模板

以每个中心（含偶数中心）向两侧扩展判断回文。

字符串DP状态机模板

正则匹配/通配符匹配等有限状态 DP 设计。

哈希映射字符串分组

按归一化字符串（排序/计数）或编码哈希分组。

编辑距离 DP 模板

经典 DP 转移：增删改三方向取最小。

数组与二分模板

数组哈希映射/分组/集合

在数组场景中使用哈希表的三类常见模式。

双指针对撞模板

左右指针从两端向中间移动，按条件收缩或更新答案。

排序加双指针模板

排序后通过左右（或三指针）实现搜索与去重。

荷兰旗三指针模板

三指针划分区间（<,=,>），原地多路划分。

排序或边界双指针

通过排序后定位边界或在原数组中扩展边界。

划分二分模板

按划分不变量设计二分（如两个数组中位数）。

旋转数组二分模板

识别有序/旋转部分，选择正确半区继续二分。

上下界二分模板

lower_bound / upper_bound 模板与不变式。

快速选择或堆模板

Quickselect 选择第 K 大，或小顶堆/大顶堆维护。

桶堆哈希组合

按频率计数（桶）+ 堆选前 K + 哈希映射。

贪心与前缀/队列模板

最远可达模板

维护当前可达最远位置与下一跳边界。

区间合并模板

按起点排序后合并重叠区间。

单次交易模板

维护最小买入价与最大利润。

Boyer-Moore 多数投票

维护候选与计数，最终验证候选是否多数。

前后缀乘积模板

预处理前缀积与后缀积，得到除自身以外乘积。

单调队列模板

双端队列维持窗口内单调性，用于滑动窗口最大值。

贪心排序插入

按规则排序后在目标位置插入，维持局部最优。

原地标记模板

利用符号/偏移在数组原地记录出现情况。

前缀和加哈希模板

维护前缀和出现次数，O(n) 查找满足条件的子数组。

贪心加桶堆组合

利用任务间隔与频率贪心安排，配合桶/堆结构。

动态规划模板

Kadane 最大子段和

维护以当前位置结尾的最大子段和并迭代更新全局最优。

二维 DP 与组合计算

网格路径与组合数的 DP 推导与公式等价。

斐波那契 DP

基础线性递推，滚动数组优化空间。

正负双 DP（乘积最大）

同时维护最大与最小乘积以应对负数翻转。

线性 DP（打家劫舍）

取或不取的线性状态转移与边界处理。

完全背包模板

可重复选择物品的背包转移与初始化。

耐心排序加二分（LIS）

维护扑克牌堆顶数组并用二分更新。

状态机 DP（股票问题）

多状态（持有/不持有/冷冻）转移的统一写法。

区间 DP 模板

枚举分割点进行区间转移（如戳气球）。

01 背包模板

一次选择与容量限制的 DP，倒序遍历优化空间。

二维 DP（矩阵）

基于邻接关系的二维 DP 转移（最大正方形/最小路径和）。

Z 字扫描或二分（矩阵）

从右上/左下出发的有序矩阵扫描或按行列二分。

字典树与位运算模板

Trie 构建与查找

前缀树节点结构与增删查模板。

DP 加字典集合

用集合或 Trie 辅助 DP 判定可拆分（如单词拆分）。

位运算异或模板

异或的消除与对称性，常用于找唯一元素。

按位 DP 模板

按位计算与缓存，用于统计类问题。

位计数模板

内置方法或位运算技巧统计不同位数。

Floyd 环检测或二分计数

链表/数组中的环检测或通过二分计数定位重复数。

图权 DFS 或并查集组合

带权图的可达性计算与并查集合并。

滑动窗口模板

滑动窗口模板

维护窗口内计数/条件，扩展与收缩的正确性与边界。

滑动窗口加计数

结合计数数组/哈希表实现异位词、覆盖子串等判定。
