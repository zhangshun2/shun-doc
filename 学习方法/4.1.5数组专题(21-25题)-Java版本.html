1️⃣ 最大矩形 (LeetCode 85)

📝 题目描述

给定一个仅包含 0 和 1 、大小为 rows x cols 的二维二进制矩阵，找出只包含 1 的最大矩形，并返回其面积。

🔧 基础解法：动态规划 + 暴力

复杂度分析：

  • 时间复杂度：O(rows × cols²)
  • 空间复杂度：O(rows × cols)

🚀 进阶解法：动态规划 + 单调栈

复杂度分析：

  • 时间复杂度：O(rows × cols)
  • 空间复杂度：O(cols)

解题思路：

  1. 将问题转化为多个”柱状图中最大矩形”问题
  2. 对每一行，计算以该行为底边的柱状图
  3. 使用单调栈优化柱状图最大矩形的计算

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(n)

🚀 进阶解法：双指针

  • 空间复杂度：O(1)

3️⃣ 寻找两个正序数组的中位数 (LeetCode 4)

📝 题目描述

给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的中位数。

算法的时间复杂度应该为 O(log (m+n))。

示例 1：

示例 2：

🔧 基础解法：合并数组

复杂度分析：

  • 时间复杂度：O(m + n)
  • 空间复杂度：O(m + n)

🚀 进阶解法：二分查找

复杂度分析：

  • 时间复杂度：O(log(min(m, n)))
  • 空间复杂度：O(1)

解题思路：

  1. 在较短的数组上进行二分查找
  2. 找到合适的分割点，使得左半部分的最大值≤右半部分的最小值
  3. 根据总长度的奇偶性计算中位数

复杂度分析：

  • 空间复杂度：O(1)

🚀 进阶解法：动态规划

  • 空间复杂度：O(1)

  3. 每次更新全局最大值

5️⃣ 多数元素 (LeetCode 169)

📝 题目描述

给定一个大小为 n 的数组 nums，返回其中的多数元素。多数元素是指在数组中出现次数大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例 1：

示例 2：

🔧 基础解法：哈希表计数

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(n)

🚀 进阶解法：Boyer-Moore投票算法

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

解题思路：

  1. Boyer-Moore投票算法的核心思想：多数元素的出现次数大于其他所有元素出现次数之和
  2. 维护一个候选者和计数器
  3. 遇到相同元素计数+1，不同元素计数-1
  4. 计数为0时更换候选者

📚 总结

🎯 核心知识点

  1. 矩阵转柱状图：二维问题转化为一维问题
  2. 双指针优化：空间复杂度从O(n)优化到O(1)
  3. 二分查找应用：在有序数组中快速定位
  4. 动态规划状态设计：同时维护最大值和最小值
  5. Boyer-Moore算法：O(1)空间找多数元素

💡 解题模式

  • 矩形问题：转化为柱状图 + 单调栈
  • 雨水问题：双指针或动态规划
  • 中位数问题：二分查找优化
  • 乘积问题：考虑负数的特殊性
  • 多数元素：投票算法的巧妙应用

🔄 刷题建议

  1. 掌握问题转化：复杂问题转化为已知问题
  2. 空间优化技巧：从O(n)到O(1)的优化思路
  3. 二分查找扩展：不仅用于查找，还能用于求解
  4. 状态机思想：动态规划中的状态转移
  5. 数学算法：Boyer-Moore等经典算法
