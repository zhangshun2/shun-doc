1.2 sk_buff内存布局

sk_buff结构体内存布局：

+-------------------+
|   sk_buff 结构    |  <- 控制信息
+-------------------+
|                   |
|   head            |  <- 指向数据缓冲区开始
|   data            |  <- 指向有效数据开始  
|   tail            |  <- 指向有效数据结束
|   end             |  <- 指向数据缓冲区结束
|                   |
+-------------------+
|                   |
|   数据缓冲区       |  <- 实际网络数据
|                   |
+-------------------+
| skb_shared_info   |  <- 分片信息
+-------------------+

内存指针关系：
head <= data <= tail <= end

可用空间：
- headroom: data - head  (用于添加头部)
- tailroom: end - tail   (用于添加尾部)
- 数据长度: tail - data

  1. sk_buff设计：灵活的网络数据包结构，支持分片和零拷贝

  3. 队列管理：线程安全的数据包队列操作
