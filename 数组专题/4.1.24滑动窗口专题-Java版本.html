🎯 滑动窗口核心思想

🔑 什么是滑动窗口？

滑动窗口是一种算法思想，通过维护一个窗口在数组或字符串上滑动，来解决一些查找满足一定条件的连续区间的问题。

📝 滑动窗口的特点

  1. 窗口内维护一定的性质：如无重复字符、字符频次等
  2. 动态调整窗口大小：根据条件扩大或缩小窗口
  3. 高效的时间复杂度：通常为O(n)，避免重复计算
  4. 双指针实现：使用左右指针维护窗口边界

  • 避免了逐个移动左指针的过程

📝 题目描述

给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的连续子数组的个数 。

示例 1：

示例 2：

🔧 基础解法：暴力枚举

复杂度分析：

  • 时间复杂度：O(n²)
  • 空间复杂度：O(1)

🚀 进阶解法：前缀和

复杂度分析：

  • 时间复杂度：O(n²)
  • 空间复杂度：O(n)

🚀 最优解法：前缀和+哈希表

复杂度分析：

  • 时间复杂度：O(n)
  • 空间复杂度：O(n)

核心思想：

  • 如果存在子数组[i,j]的和为k，那么 prefixSum[j] - prefixSum[i-1] = k
  • 即 prefixSum[i-1] = prefixSum[j] - k
  • 使用哈希表记录每个前缀和出现的次数
  • 遍历数组时，查找是否存在 prefixSum - k 的前缀和

注意： 此方法仅适用于所有元素都为正数的特殊情况，对于包含负数的一般情况，应使用前缀和+哈希表的方法。

📚 滑动窗口专题总结

🎯 核心知识点回顾

1. 滑动窗口的本质

  • 双指针技术：使用左右指针维护窗口边界
  • 动态调整：根据条件动态扩大或缩小窗口
  • 状态维护：在窗口滑动过程中维护必要的状态信息
  • 高效计算：避免重复计算，实现O(n)时间复杂度

2. 滑动窗口的类型

固定大小窗口
  • 窗口大小固定，只需要滑动窗口位置
  • 典型应用：找到字符串中所有字母异位词
  • 实现方式：维护固定长度的窗口，逐步移动
可变大小窗口
  • 窗口大小根据条件动态调整
  • 典型应用：无重复字符的最长子串
  • 实现方式：根据条件扩大或缩小窗口

3. 滑动窗口的应用场景

  1. 子串/子数组问题：查找满足条件的连续区间
  2. 字符串匹配：模式匹配、异位词检测
  3. 数组统计：连续元素的统计分析
  4. 优化问题：最长、最短、最大、最小等优化目标

4. 常用的数据结构

  1. HashMap/HashSet：记录字符频次、去重
  2. 数组：固定字符集的频次统计
  3. 双端队列：维护窗口内的最值
  4. 前缀和：快速计算区间和

💡 解题模式总结

1. 无重复字符类问题

2. 字符频次匹配类问题

3. 固定窗口大小类问题

4. 前缀和优化类问题

🔄 算法选择指南

何时使用滑动窗口？

  1. 连续子串/子数组问题：需要查找连续区间
  2. 字符串模式匹配：异位词、包含关系等
  3. 优化目标明确：最长、最短、计数等
  4. 可以增量更新：窗口状态可以增量维护

滑动窗口 vs 其他算法

  1. vs 暴力枚举：时间复杂度从O(n²)优化到O(n)
  2. vs 动态规划：空间复杂度更优，实现更简单
  3. vs 分治算法：适用于连续区间问题
  4. vs 贪心算法：能保证全局最优解
